# OOPS Lab Practical Assignments

C++ programs for Object-Oriented Programming Lab.

## Experiments

1. **Experiment 01**: Data Types, Variables, Constants, Operators, and Formatted I/O
2. **Experiment 02**: Bank Account Class Hierarchy and Access Specifiers
3. **Experiment 03**: Constructor Types (Default, Parameterized, Copy, Move) and Destructor
4. **Experiment 04**: Single and Multilevel Inheritance
5. **Experiment 05**: Runtime Polymorphism and Abstract Class Shape
6. **Experiment 06**: Compile-Time Polymorphism (Function and Operator Overloading)
7. **Experiment 07**: Generic Stack Class using Templates
8. **Experiment 08**: STL Containers (vector, map) and Algorithms (sort, find_if)
9. **Experiment 09**: Custom Exception Hierarchy in Banking System
10. **Experiment 10**: CSV File Handling with Stream Pointers (tellp, seekg, tellg)
11. **Experiment 11**: Mini Project - Student Management System

## Compilation Command

```bash
g++ main.cpp -o main.exe
.\main.exe
```
